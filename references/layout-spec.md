# Layout Spec — 硬性排版约束

数值在 Chrome 里实测标定过（1080×1440，`.content` padding `48px / 80px` → 内容框 `920 × 1344`，
intro 字号/行高 38px / 1.75 → 每行 66.5px / 每行 ≤24 字宽）。

**唯一的溢出解法是改写文案。** 不允许改字号、改行高、改 padding、改图片比例、加 `flex:1` 撑开。

---

## 0. 卡片结构

固定竖向顺序，不可增删、不可换序：

```
profile-head → intro → photo → grow
```

一张卡 = 一张 PNG，没有封面/章节的区分。一次可以出多张卡（批量发图），每张卡的四个区块完全同构，
只有文案、图片和页码不同。

## 1. 头部 `.profile-head`

固定高度 152px（104 头像行 + 48 margin-bottom），不随内容变化。**头像区和正文之间没有分割线**，
靠间距分隔就够了。

**头像/昵称/bio 是整批共用的账号身份，只在 `:root` 配置一次**（`--account-avatar` /
`--account-name` / `--account-bio`），不写进每张卡的 markup，靠 CSS `content: var(...)` /
`background-image: var(...)` 应用到所有 `.poster`。每张卡自己只填页码。

| 元素 | 配置位置 | 内容约束 |
| --- | --- | --- |
| 头像 | `:root { --account-avatar: url("…") }` | 展示为 104×104 圆形裁切（`background-size: cover`），传入图不必是正方形 |
| 昵称 | `:root { --account-name: "…" }` | ≤ 10 字宽，粗体 38px，**accent 色**（`var(--accent)`，当前是橙色 `#ff6b35`，和卡片描边共用同一个 accent；**认证图标是独立的 `var(--verified)` 固定蓝色 `#1d6fd6`，不跟 accent 走**），**认证图标固定跟在昵称后面**，不做可选开关 |
| bio | `:root { --account-bio: "…" }` | 单行，≤ 22 字宽，**24px 灰色，全卡唯一不放大的字号** |
| 页码 | `.page-index`（每张卡自己填） | 右上角，格式固定 `NN / MM`（当前页 / 本次批量总张数），两位数字，如 `01 / 03`，24px |

## 2. 正文 `.intro`

| 项 | 约束 |
| --- | --- |
| 字号/行高 | 38px / 1.75 → 每行 66.5px，每行 ≤ 24 字宽 |
| 段落数 | 1–2 段（`<p>`），段间距 28px |
| 单段行数 | ≤ 10 行（等于总行数上限——只写 1 段、占满整个预算也可以） |
| 总行数 | **7–10 行**（由头部 152px + 图片 460px + 间距倒推出的固定区间，见下方推导） |
| 总结句 | **每段第一句必须是这段的总结句**，用 `<strong>` 包住（加粗 + 下划线，模板已定义样式）。 一段只能有 1 个 `<strong>`，且必须在段首——不是随便加粗一个词，是"读者只看加粗句就懂这段在说什么"的那句话 |
| 禁止 | 列表、表格、代码块、emoji、手动 `<br>`、`<img>`、`<em>`（强调统一用段首 `<strong>` 总结句，不再用 `<em>` 单词高亮） |

**行数区间怎么来的**：内容框 1344px − 头部 152px − 图片 460px − intro 与图片间距 32px = 700px 可用。
按 66.5px/行折算，700px 最多装 10 行（10×66.5=665，11 行需要 731.5px，超出可用空间，图片会被顶出内容框）。
下限按可读性定在 7 行（对应 `.grow` 留白 234.5px），上限 10 行对应 35px。**7–10 行都是合规区间**，
一段或两段都可以，不强制写满上限——内容本来就短，留白比硬凑字数更合适。

## 3. 图片 `.photo-frame`

| 项 | 约束 |
| --- | --- |
| 尺寸 | **固定 920 × 460（2:1）**，不许改 |
| 填充方式 | `object-fit: fill`（拉伸铺满，不裁切）。来源图片尺寸不需要精确等于 2:1，
  接近即可——偏离越大拉伸感越明显，明显偏离（如竖图、正方形）应先自己crop 到接近 2:1 再传入 |
| 圆角 | 24px，模板已写死 |
| 数量 | 每张卡固定 1 张，不放第二张，图片下方不再接文字 |

## 4. 底线

1. 一张卡只有 `.profile-head` + `.intro` + `.photo-frame` 三个内容区块，不加第四个。
2. 图片下方没有正文——如果想写「图后感想」，另开一张卡，不要塞进同一张。
3. 不放 emoji、装饰色块、第二张图。
4. 不编造头像/昵称/bio 之外的身份信息。
5. 页码是批量出图时的位置指示，不是猜的——按实际产出的张数和顺序填。
