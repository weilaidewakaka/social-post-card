# Layout Spec — 硬性排版约束

数值在 Chrome 里实测标定过（1080×1440，`.content` padding `48px / 80px` → 内容框 `920 × 1344`，
title 字号/行高：封面 112px / 1.32 → 每行 ≤8 字宽、内容卡 66px / 1.32 → 每行 ≤13 字宽，
intro 字号/行高 38px / 1.75 → 每行 66.5px / 每行 ≤24 字宽）。

**唯一的溢出解法是改写文案。** 不允许改字号、改行高、改 padding、改图片比例、加 `flex:1` 撑开。

---

## 0. 卡片结构：两种卡、两种出图模式

两种卡，各自固定竖向顺序，不可增删、不可换序：

```
封面卡（section 带 .cover）：profile-head → title（2 行）→ intro（1 段）→ photo → grow
内容卡                    ：profile-head → title（1 行）→ intro（1–3 段）→ grow
```

两种出图模式，只有这两种组合：

| 模式 | 组成 | 页码 |
| --- | --- | --- |
| 单页短分享 | 1 张内容卡，没有封面 | `01 / 01` |
| 长文分享 | 1 张封面卡 + N 张内容卡（N ≥ 1，一章一张，此时内容卡也叫章节卡） | `01 / (N+1)` 起 |

封面卡负责吸引点开，配 1 张图；内容卡纯文字，不配图——长文一次也只需要准备 1 张配图。
多张卡必须带封面；只有封面、没有章节卡也不成立。

## 1. 头部 `.profile-head`（两种卡通用）

固定高度 152px（104 头像行 + 48 margin-bottom），不随内容变化。**头像区和正文之间没有分割线**，
靠间距分隔就够了。

**头像/昵称/bio 是整批共用的账号身份，只在 `:root` 配置一次**（`--account-avatar` /
`--account-name` / `--account-bio`），不写进每张卡的 markup，靠 CSS `content: var(...)` /
`background-image: var(...)` 应用到所有 `.poster`。每张卡自己只填页码。

| 元素 | 配置位置 | 内容约束 |
| --- | --- | --- |
| 头像 | `:root { --account-avatar: url("…") }` | 展示为 104×104 圆形裁切（`background-size: cover`），传入图不必是正方形 |
| 昵称 | `:root { --account-name: "…" }` | ≤ 10 字宽，粗体 38px，**accent 色**（`var(--accent)`，和卡片描边共用同一个 accent；**认证图标是独立的 `var(--verified)` 固定蓝色 `#1d6fd6`，不跟 accent 走**），**认证图标固定跟在昵称后面**，不做可选开关 |
| accent 颜色 | `<body>` 的 class：`accent-orange`（橙 `#ff6b35`，默认）/ `accent-blue`（蓝 `#2563eb`） | 整批卡片二选一，`<body>` 只放一个 accent class；不接受自定义色值，不做第三个颜色 |
| bio | `:root { --account-bio: "…" }` | 单行，≤ 22 字宽，**24px 灰色，全卡唯一不放大的字号** |
| 页码 | `.page-index`（每张卡自己填） | 右上角，格式固定 `NN / MM`（当前页 / 本次批量总张数），两位数字，如 `01 / 04`，24px |

## 2. 封面卡专属区块

### 2.1 大标题 `.title`

黑体粗体（`font-weight: 700`），黑色；字号两种卡不同：封面 112px，内容卡 66px（模板用
`.cover .title-line` 覆盖——封面靠 section 的 `.cover` 识别，不能用 `#p01`，单页模式的内容卡
也是 p01；也不能用 `:first-of-type`，单卡渲染时每张卡都是唯一 poster）；行数封面 2 行、内容卡 1 行（见 §3）。

**封面卡：**

| 项 | 约束 |
| --- | --- |
| 字号/行高 | 112px / 1.32 |
| 行数 | **固定 2 行**，两行是独立的 `.title-line` 元素，不靠自动换行——由内容约束（字数）保证，不是排版猜测 |
| 每行字数 | ≤ 8 字宽（920px 内容宽 ÷ 112px ≈ 8.2，取整 8，留安全边距） |
| 总字数 | ≤ 16 字宽（两行相加） |
| 占用高度 | 2 × 112×1.32 ≈ 295.7px + margin-bottom 32px ≈ 327.7px（固定，不随文案变化） |
| 禁止 | emoji、手动缩短一行硬凑二行、单行放不下时改字号 |

**内容卡：**

| 项 | 约束 |
| --- | --- |
| 字号/行高 | 66px / 1.32 |
| 下划线 | **带下划线**（4px 厚、偏移 8px，黑色）。正文不加粗，标题下划线是整张卡唯一的视觉锚点；封面大标题不带 |
| 行数 | **固定 1 行**，只有 1 个 `.title-line` 元素，不可两行 |
| 字数 | ≤ 13 字宽（920px ÷ 66px ≈ 13.9，取整 13） |
| 占用高度 | 66×1.32 ≈ 87.1px + margin-bottom 32px ≈ 119.1px（固定） |
| 禁止 | emoji、两行、超 13 字宽 |

### 2.2 正文 `.intro`（封面卡：1 段）

| 项 | 约束 |
| --- | --- |
| 字号/行高 | 38px / 1.75 → 每行 66.5px，每行 ≤ 24 字宽 |
| 段落数 | 固定 1 段（`<p>`） |
| 总行数 | **固定 4 行**（≈73–96 字宽，由头部 152px + 标题 327.7px + 图片 460px + 间距倒推，见下方推导） |
| 禁止 | 列表、表格、代码块、emoji、手动 `<br>`、`<img>`、`<strong>`/`<em>`（封面卡不加粗，纯正文即可） |

**行数怎么来的**：内容框 1344px − 头部 152px − 标题 327.7px（112px×1.32×2 + 32 margin）− 图片 460px
− intro 与图片间距 32px ≈ 372.3px 可用。按 66.5px/行折算，4 行（4×66.5=266）时 `.grow` 留白
约 106px，5 行只剩约 40px、观感拥挤，6 行直接顶出内容框。规范定为
**固定 4 行**：给图片上方留出可辨识的呼吸空间，也让封面文字保持"一眼扫完"的密度。

### 2.3 图片 `.photo-frame`

| 项 | 约束 |
| --- | --- |
| 尺寸 | **固定 920 × 460（2:1）**，不许改 |
| 填充方式 | `object-fit: fill`（拉伸铺满，不裁切）。来源图片尺寸不需要精确等于 2:1，
  接近即可——偏离越大拉伸感越明显，明显偏离（如竖图、正方形）应先自己crop 到接近 2:1 再传入 |
| 圆角 | 24px，模板已写死 |
| 数量 | 只出现在封面卡，固定 1 张，不放第二张，图片下方不再接文字 |

## 3. 内容卡专属区块：标题 `.title`（1 行）+ 正文 `.intro`（1–3 段）

单页模式的那张卡和长文模式的章节卡是同一种内容卡，规则完全一样。

**标题**：见 §2.1 内容卡表——固定 1 行，≤ 13 字宽，复用封面卡的 `.title` / `.title-line` 样式。

**正文：**

| 项 | 约束 |
| --- | --- |
| 字号/行高 | 38px / 1.75 → 每行 66.5px，每行 ≤ 24 字宽 |
| 段落数 | **1–3 段**（`<p>`），段间距 28px。段数跟着内容走，不为凑段数拆段 |
| 单段行数 | **不限**，只受整卡总行数约束 |
| 总行数 | **6–14 行**（各段相加，单段行数按 `ceil(字宽 ÷ 24)` 计） |
| 加粗 | **不加粗**，正文全部是纯文本 |
| 禁止 | 列表、表格、代码块、emoji、手动 `<br>`、`<img>`、`<strong>`/`<b>`、`<em>` |

**上限怎么来的**：内容框 1344px − 头部 152px − 标题 119.1px ≈ 1072.9px 可用。按 66.5px/行折算，
14 行 3 段（14×66.5=931 + 2×28 段距 = 987）时 `.grow` 留白约 86px；15 行需要 1053.5px，`.grow`
只剩约 19px，观感拥挤，所以封顶在 14 行。段数越少段距越少，1 段 14 行时留白约 142px。

**下限只卡整卡**：6 行是"一张卡看起来不空"的底线，单段不设地板——卡单段等于给每段设了
字数地板，内容不够就会被同义复述和缓冲句填满。

## 4. 底线

1. 封面卡只有 `.profile-head` + `.title`（2 行）+ `.intro`（1 段）+ `.photo-frame` 四个内容区块；
   内容卡只有 `.profile-head` + `.title`（1 行）+ `.intro`（1–3 段）三个内容区块。两种卡都不加多余的区块。
2. 图片只出现在封面卡，且图片下方没有正文——如果想写「图后感想」，放进内容卡的正文段落，不要塞进封面卡。
3. 不放 emoji、装饰色块、第二张图。
4. 不编造头像/昵称/bio 之外的身份信息。
5. 页码是批量出图时的位置指示，不是猜的——按实际产出的张数和顺序填（长文封面卡永远是 01，
   单页模式固定 `01 / 01`）。
